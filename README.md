# Climate change and early-life health: reproducibility materials

This repository contains the processed figure data, R code and epidemiological model specification accompanying a study of anthropogenic climate change, early-life health impairments, human capital losses and economic costs in low- and middle-income countries.

The public materials reproduce the quantitative manuscript figures using aggregated or de-identified plotting objects. Individual-level DHS-derived analytic data are access-controlled and are not distributed through this repository.

## Repository structure

| Directory | Description |
|---|---|
| `R/` | Figure scripts, shared plotting functions, multistate survival models and data-preparation code. |
| `data/` | Public `.RData` objects containing aggregated plotting data and published model results. |
| `data-restricted/` | Instructions for reconstructing access-controlled DHS-derived inputs. |
| `outputs/reference/` | Reference images extracted from the manuscript for visual comparison. |
| `outputs/reproduced/` | Destination for figures generated by the supplied R scripts. |

Extended Data Figure 2 and panels a and d of Extended Data Figure 3 are not included because they do not require separate R-derived quantitative plotting data. The repository includes the data-driven panels b and c of Extended Data Figure 3.

## Software requirements

The workflow was tested using R 4.4.2.

```r
install.packages(c(
  "ggplot2", "patchwork", "sf", "rnaturalearth", "viridis",
  "data.table", "mstate", "survival", "metafor"
))
```

## Quick start in RStudio

1. Clone or download this repository.
2. Open `early-life-reproducibility.Rproj` in RStudio.
3. Generate all included figures:

```r
source("R/run_all_figures.R")
```

Generated figures are saved in `outputs/reproduced/`. Individual figures can also be generated by opening the corresponding script and clicking **Source**.

```r
source("R/01_figure1_temperature_maps.R")
source("R/03_figure3_attribution.R")
source("R/08_extended_data_figure3_multistate_framework.R")
```

## Command-line use

The scripts remain compatible with `Rscript` when run from the repository root:

```bash
Rscript R/run_all_figures.R
```

## Figure 2 epidemiological model

Figure 2 is based on region-specific multistate Cox models in which miscarriage, stillbirth, small vulnerable newborn (SVN) and term non-SVN live birth are represented as mutually exclusive absorbing states from ongoing pregnancy. Heat and cold are defined using country-specific temperature percentiles, with the 50th–60th percentile as the reference. Region-specific transition hazard ratios are pooled using random-effects meta-analysis.

The individual-level model input must be reconstructed locally from an authorized DHS-derived analytic file.

```r
options(earlylife.dhs_analytic_csv = "path/to/data_analysis_clean.csv")
source("R/09_build_restricted_model_input.R")

# Omit this option to fit all regions.
options(earlylife.regions = c("Central Asia & Europe"))
source("R/10_figure2_multistate_model.R")
```

The workflow was smoke-tested by refitting Central Asia and Europe. The six heat- and cold-related outcome estimates and their confidence intervals reproduced the published regional estimates to two decimal places.

## Data access and privacy

The public `.RData` files contain only aggregated, figure-level or de-identified records. The public Figure 1 object is provided on a 0.5-degree grid without pregnancy identifiers, DHS cluster identifiers or exact DHS coordinates.

Individual-level Figure 2 inputs and exact DHS-derived spatial objects are excluded from the public repository. Researchers wishing to refit these models must obtain authorization to access DHS data and reconstruct the inputs using the supplied preparation scripts. DHS-derived data remain subject to the DHS Program terms of use.
