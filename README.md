# Climate change and early-life health: reproducibility materials

This repository contains the processed figure data, R code and epidemiological
model specification accompanying a study of
anthropogenic climate change, early-life health impairments, human capital
losses and economic costs in low- and middle-income countries.

This release is aligned with the 11 August 2026 manuscript and the final
loss-only Figure 4 and Figure 5 data objects. Figure 3 is retained unchanged
from the preceding reproducibility release.

Repository: [ZhenghongZhu/Anthropogenic-climate-change-exacerbates-extreme-temperature-related-ELHBs-and-HCLs](https://github.com/ZhenghongZhu/Anthropogenic-climate-change-exacerbates-extreme-temperature-related-ELHBs-and-HCLs)

The public materials reproduce the quantitative manuscript figures from
aggregated or de-identified plotting objects. They also document the complete
multistate survival modelling workflow underlying the temperature and
early-life health associations. A fully synthetic individual-level dataset is
provided so that the model code can be executed without access to DHS
microdata. Individual-level DHS-derived analytic data remain access-controlled
and are not distributed through this repository.

## Repository structure

| Directory | Description |
|---|---|
| `R/` | Figure scripts, shared plotting functions, multistate survival modelling code and data-preparation scripts. |
| `data/` | Public plotting objects, published model results and a fully synthetic individual-level dataset for testing the Figure 2 model code. |
| `data-restricted/` | Documentation and local placeholders for access-controlled DHS-derived inputs. Restricted `.RData` files are excluded from Git. |
| `outputs/reference/` | Reference images extracted from the manuscript for visual comparison. |
| `outputs/reproduced/` | Destination for figures generated by the supplied R scripts. Generated images are not committed. |
| `outputs/model/` | Destination for simulated or authorized Figure 2 model results. Generated model results are not committed. |

Extended Data Figure 2 and the conceptual panels a and d of Extended Data
Figure 3 are not included because they do not require separate R-derived
quantitative plotting data. The repository includes the data-driven panels b
and c of Extended Data Figure 3.

using R 4.4.2. RStudio is optional; all scripts can also be run with
`Rscript`. No non-standard hardware or GPU is required.

## Quick start in RStudio

1. Clone or download this repository.
2. Open `early-life-reproducibility.Rproj` in RStudio.
3. Run all included figure scripts:

```r
source("R/run_all_figures.R")
```

Generated figures are written to `outputs/reproduced/`. Individual figures can
also be generated by opening the corresponding script in RStudio and clicking
**Source**, or by running, for example:

```r
source("R/01_figure1_temperature_maps.R")
source("R/03_figure3_attribution.R")
source("R/08_extended_data_figure3_multistate_framework.R")
```

The expected output is seven PNG files: Figures 1-5, Extended Data Figure 1,
and a combined image containing panels b and c of Extended Data Figure 3. The
workflow also prints a successful release-validation message after checking
the principal Figure 4 and Figure 5 values. On the tested Windows system, the
complete public workflow took approximately 21-24 seconds after package
installation; allowing 1-3 minutes is reasonable on a typical desktop.

The public workflow was also tested from a directory containing non-ASCII
characters. `R/00_common.R` includes a Windows UTF-8 safeguard and falls back
to the active project directory if the command-line script path cannot be
normalized.

The full workflow also runs `R/11_validate_release.R`, which checks the public
Figure 4 and Figure 5 objects against the key values reported in the current
manuscript. It can be run separately with:

```r
source("R/11_validate_release.R")
```

## Attribution and loss-only conventions

Country-specific 10th and 90th percentiles define cold and heat exposure in
the attribution analysis. For each country, pregnancy outcome and exposure,
the signed number attributable to anthropogenic climate change (ACC) is
calculated from the difference between factual and counterfactual population
attributable fractions:

```text
N_ACC = N_2015 * P_outcome * (PAF_factual - PAF_counterfactual)
```

The relative attributable proportion is reported as:

```text
AP = (PAF_factual - PAF_counterfactual) /
     max(PAF_factual, PAF_counterfactual) * 100%
```

For the loss-and-damage maps in Figures 4 and 5, adverse components are
retained before aggregation:

```text
N_loss = max(N_ACC, 0)
```

This operation is applied separately by country, exposure and outcome. Heat-
and cold-related losses are then summed; avoided impacts in one population or
outcome do not offset losses in another. The processed Figure 4 and Figure 5
objects propagate uncertainty using 500 Monte Carlo simulations.

These are processed plotting objects: the public figure workflow redraws the
figures and validates the principal reported values, but does not rerun the
upstream attribution, uncertainty-propagation or economic-valuation pipeline.

SVN-related neonatal mortality is estimated from all ACC-attributable SVN
cases. Other long-term health, cognitive and non-cognitive outcomes use the
surviving SVN population after excluding SVN-related neonatal deaths. This
denominator convention is already reflected in the public Figure 4 and Figure
5 plotting objects.

## Figure 2 epidemiological model

Figure 2 is based on region-specific multistate Cox models in which
miscarriage, stillbirth, small vulnerable newborn (SVN) and term non-SVN live
birth are represented as mutually exclusive absorbing states from ongoing
pregnancy. Heat and cold are defined using country-specific temperature
percentile categories, with the 50th-60th percentile as the reference.
Region-specific transition hazard ratios are pooled by random-effects
meta-analysis using restricted maximum likelihood.

The repository contains the model specification, published coefficient tables,
pooled estimates and plotting data. It also includes
`data/Figure2_simulated_model_input.RData`, a fully synthetic dataset with the
same variable structure required by the model. It contains no DHS observations
and is intended only to demonstrate code execution.

Run the complete eight-region model demonstration in RStudio with:

```r
source("R/10_figure2_multistate_model.R")
```

For a faster single-region test:

```r
options(earlylife.regions = "Central Asia & Europe")
source("R/10_figure2_multistate_model.R")
```

The resulting `.RData` file is written to `outputs/model/`. Estimates obtained
from the synthetic data are software-validation outputs and must not be
interpreted as manuscript results. The published Figure 2 remains reproduced
from `data/Figure2_plot_data.RData`. On the tested system, the single-region
model took approximately 4 seconds and the complete eight-region demonstration
took approximately 16 seconds.

The simulated input can be regenerated deterministically with:

```r
source("R/07_generate_figure2_simulated_input.R")
```

To refit the model using an authorized DHS-derived input, first construct the
restricted model object:

In RStudio:

```r
options(earlylife.dhs_analytic_csv = "path/to/data_analysis_clean.csv")
source("R/09_build_restricted_model_input.R")

# Omit this option to fit all regions.
options(earlylife.regions = c("Central Asia & Europe"))
options(
  earlylife.figure2_model_input =
    "data-restricted/Figure2_model_input.RData"
)
source("R/10_figure2_multistate_model.R")
```

At the command line:

```bash
Rscript R/09_build_restricted_model_input.R "path/to/data_analysis_clean.csv"
FIGURE2_MODEL_INPUT="data-restricted/Figure2_model_input.RData" \
  Rscript R/10_figure2_multistate_model.R
```

On Windows PowerShell, set the same path with:

```powershell
$env:FIGURE2_MODEL_INPUT = "data-restricted/Figure2_model_input.RData"
Rscript R/10_figure2_multistate_model.R
```

The packaged workflow was smoke-tested by refitting Central Asia and Europe.
The six heat- and cold-related outcome estimates and their confidence intervals
reproduced the published regional estimates to two decimal places.

The synthetic model demonstration and the authorized DHS refit are kept
separate from `R/run_all_figures.R` because neither is used to redraw the
published Figure 2 from the fixed public plotting object.

## Data access and privacy

The public `.RData` files contain aggregated, figure-level, de-identified or
fully synthetic records. The public Figure 1 object is released on a
0.5-degree grid and does not contain pregnancy identifiers, DHS cluster
identifiers or exact DHS coordinates. The simulated Figure 2 input was
generated independently of DHS records. Authorized individual-level Figure 2
inputs and exact DHS-derived spatial objects remain in `data-restricted/` and
are excluded by `.gitignore`.

Researchers wishing to refit the individual-level models must obtain their own
authorization to access DHS data and reconstruct the model input using the
supplied preparation script. DHS-derived data remain subject to the DHS Program
terms of use.
